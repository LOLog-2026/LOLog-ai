# 실험 1. TTS 속도·메모리

## 목적

카드 영상(FR-EXT-02)의 대사를 화자 목소리로 읽을 수 있는지, Jetson 3호에서 돌릴 만한 속도·메모리인지 확인한다.
기본 화자의 인사 클립(#27, "안녕하세요! 만나서 반가워요.")을 참조 음성으로 넣어 같은 목소리로 대사를 읽는다.

## 설정

- 모델: `Qwen/Qwen3-TTS-12Hz-0.6B-Base` (클론). 코드는 `src/lolog_ai/tts.py`
- 대사 8개(2~34자, 화자 5명). `bench_clone.py`의 `LINES`
- 읽는 길이 한도: 글자 수 × 0.45초(최소 4초). 한도의 1.5배에서 생성을 끊고, 한도를 넘으면 시드를 바꿔 3번까지 다시 읽는다
- "ㅋㅋㅋ", "ㅠㅠ" 같은 낱자모는 읽을 때만 뺀다(자막에는 둔다)

## 돌리는 법

```bash
uv venv --python 3.12 .venv && uv pip install -p .venv qwen-tts soundfile   # 워커 환경과 따로(transformers 버전이 다름)
.venv/bin/python -I bench_clone.py VOICES_DIR out
```

`VOICES_DIR`은 #27의 `out/default-voices`(`<id>.wav` 24개). 결과는 `out/result.json`과 대사별 wav.

|---|---|---|---|---|---|

- 길이 한도를 넣기 전에는 "ㅋㅋㅋ 진짜 미치겠다"에서 9분 넘게 끝나지 않았다. 낱자모를 빼고 생성 길이를 끊은 뒤에는 1.68초로 읽었다
- Jetson 3호: 대사 8개를 모두 읽었다. 남은 시스템 메모리는 5,433MB에서 최저 2,472MB(약 3GB 사용). 첫 대사만 rtf 6.41, 나머지는 5.2~5.6. 모델을 처음 받을 때는 올리는 데 86~110초 걸렸다

# 실험 2. TTS 정확도와 모델 비교 (2026-11-11, 3090)

기준과 절차는 [EVAL_PLAN.md](EVAL_PLAN.md). 대사 144개(`testset.json`, 일반 120 + 어려움 24), 화자 24명이 6개씩.
채점: 읽기는 Whisper large-v3-turbo 받아쓰기의 글자 오류율(CER), 목소리는 TTS와 상관없는 화자 인식 모델
(`microsoft/wavlm-base-plus-sv`)로 24명 인사 클립 중 가장 가까운 클립. 돌린 명령은 `eval_accuracy.py` 맨 위,
여러 실행을 차례로 돌린 대기열은 `/workspace/tts-eval/queue.txt`(서버, 레포 밖).

### 일반 대사 120개

|---|---|---|---|---|---|---|---|

| 0.6B, 화자 벡터만 (`xvec`) | 89.2% | 3.8% | 94.2% | 53.3% | 100% | 0 | 1.54 |
| 1.7B (`big17`) | 92.5% | 3.4% | 96.7% | 60.0% | 100% | 0 | 1.55 |

| Chatterbox Multilingual | 75.0% | 145% | 95.8% | 55.8% | 96.7% | 0 | 0.86 |

`final` 외에는 모두 바꾼 목소리(`final`과 같은 인사 클립)로 읽었다(`icl`, `xvec` 제외).

- **목소리 2개 교체**: `kid-f-04`(#27 후보 1번)는 Qwen 화자 인코더로 잰 자기 묶음 일치가 2/6 → 6/6. `young-m-03`은 세 후보 모두 6개 중 3개를 잘못 읽어서, 목소리 설명에서 "소리치듯"을 빼고 새로 만들었다(`voice_design.json`, 후보 2번). 6개 중 5개 통과, 남은 1개는 "혼고기"라는 낯선 낱말
- **1.7B**: 나아지지 않았다. 짧은 대사(2~6자)에서 오히려 더 틀렸다(읽기 86.7%, 0.6B 93.3%). 메모리는 4.2GB(0.6B 2.3GB)
- **temperature 0.6, 마침표**: 차이 없음(대사 2개 안쪽)
- **확인 후 다시 읽기**: whisper-small(채점과 다른 모델)로 받아써서 CER 10%를 넘으면 시드를 바꿔 3번까지 다시 읽는다. 읽기 +0.8%p(대사 1개)로 오차 범위 안이고 시간은 20% 더 든다. Jetson에서는 받아쓰기 모델이 메모리를 더 써서 넣지 않는다
- **Chatterbox**: 속도는 Qwen의 두 배지만 한국어 읽기가 크게 나쁘다. 짧은 대사에 엉뚱한 말을 길게 붙여 평균 CER이 100%를 넘었다. 설치할 때 `setuptools<81`이 필요했다(워터마크 모듈이 `pkg_resources`를 씀)
- **읽기 실패의 내용**(`final` 7개): Whisper가 소리가 같은 글자로 받아쓴 것("걔→개", "베고→배고")이 2개, TTS가 틀렸을 가능성이 있는 것("오 어땠어→오후소", "첫날 옷→첫나루")이 5개. 귀로 확인 필요

### 어려운 대사 24개 (`final`)

읽기 23/24 통과. 숫자("3시", "5만 원"), 영어("PT", "OK"), 낱자모, 느낌표·말줄임표, 한 글자 대답 모두 읽었다. 실패 1개는 "하하하하"를 "하하하"로 읽은 것.

### 목소리 지표에 대해

- 처음에는 Qwen TTS 자신의 화자 인코더로 쟀다(나이대·성별 일치 95.8%). TTS와 같은 인코더라 유리하게 나와서 독립된 WavLM으로 바꿨더니 59~63%가 됐다
- 틀린 것은 거의 모두 **성별은 맞고 나이대만 옆**이다(젊은 여자 → 중년 여자 12건, 중년 남자 → 젊은 남자 9건). WavLM은 어른 목소리로 배워서 합성 목소리의 나이대를 잘 가리지 못한다. 그래서 합격 판단은 **성별 일치**로 하고, 나이대는 귀로 듣는다
- 성별이 틀린 5건 중 4건이 `kid-m-03`이다. 여덟 살 남자아이 목소리라 높아서 여자아이로 보일 수 있다. 귀로 들어 보고 어색하면 이 화자 클립도 바꾼다

## 실험 1·2 결론

- **Qwen3-TTS 0.6B Base, 인사 클립 통째로(icl), 바꾼 목소리 24개**로 정한다. 더 큰 모델, 생성 설정, 다른 모델(Chatterbox) 모두 나아지지 않았다
- XTTS-v2는 비상업 라이선스(CPML) 동의가 필요해 돌리지 않았다
- `kid-m-03` 목소리와 읽기 실패 5개를 귀로 들어 본다
- 3090에서는 읽힌다. 실제 길이보다 1.6배 걸리므로 30초 영상의 대사는 약 50초
- Jetson 3호에서는 실제 길이보다 5.4배 걸린다. 30초 영상의 대사는 약 2분 40초, 모델 올리는 시간 약 20초. 메모리는 2.4GB가 남아 TTS만 올리기에 충분하다
- 읽은 내용이 대사와 맞는지는 실험 2에서 받아쓰기로 확인했다(읽기 94.2%)

# 실험 3·4. 영상 만들기 (2026-11-12, 3090)

카드 12개(감지 평가셋 이야기, 웃김·황당·추억 4개씩, 3개는 기본 화자 그림을 붙임)로 콘티 → TTS → 그림 → mp4를
끝까지 만들었다(`run_batch.sh`, 결과는 서버 `/workspace/video-demo/batch`, `batch2`). 그림은 장면마다 눈으로 셌다.

|---|---|---|
| 영상까지 만들어짐 | 9/12 | **12/12** |
| 콘티 검사 한 번에 통과 | 6/12 | **12/12** |
| 장면 수 / 영상 길이 | 5~8장 / 19~25초 | 5~7장 / 19~25초 |
| 카드당 시간 | 약 1분(콘티+TTS 40~55초, 그림+합치기 21~29초) | 같음 |
| 장면마다 성별·옷이 바뀐 영상 | 9개 중 3~4개 | 12개 중 1~2개 |
| 간판·현수막 글씨가 보인 영상 | 9개 중 3개 | 0개 |
| 말풍선·종이에 가짜 글씨 | 드묾 | 73장 중 약 5장 |
| 한 장이 두 칸으로 나뉨 | 52장 중 0장 | 73장 중 1장 |
| 기본 화자 그림 참조 | 2개 모두 같은 얼굴 | 3개 모두 같은 얼굴 |

2차에서 코드가 맞춘 것(`worker/video_gen.py`): 40자를 넘는 대사를 띄어쓰기에서 나누기, 지금 장면에서 말하는 화자가
cast에 없으면 넣기, 자리 겹침 다시 정하기, 외모 글에 성별 말이 없으면 붙이기, 윗옷에 색이 없으면 색 정하기,
장소·장면 설명에서 간판·현수막 말 지우기.

남은 것
- 카드에 성별 정보가 없어서 LLM이 화자를 대부분 남자로 정한다(1차 9개 중 7개가 두 화자 모두 남자). 화자에 그림이나 목소리를 붙이면 해결된다
- FLUX가 말하지 않은 사람을 한 명 더 그리거나 같은 사람을 두 번 그리는 장면이 있다
- 쪽지·휴대폰처럼 글이 있을 법한 물건이 나오면 가짜 글씨나 빈 말풍선이 생긴다

  - 장면 글에는 나오는데 콘티 `cast`·`extras`에 없는 사람(s14·s52 할아버지·할머니, s80 원피스 여자 등 약 7장). 회상이 아닌 장면에는 `extras` 보정을 하지 않아서 생겼다
  - 모르는 사람이 한 명 더 끼어듦(약 8장)
- **B1(글자, 8장 실패)**: 쪽지·문자·번호판이 나오는 장면이다. 장면 글에 `written on it`, `the text reads`, `The numbers are 20`처럼 글자를 그리라는 말이 남아 있었다. `says`를 `speaks`로 바꾼 것이 오히려 빈 말풍선을 불렀다(s31 4번)
- **B2(칸 나눔, 2장)**: s17 4번, s58 5번. 장면 글이 "다음 날", "장면이 바뀌어"처럼 시간·장소가 두 개인 장면이다
- **B7(참조 얼굴)**: s31은 머리·콧수염·옷은 같지만 참조 그림에 없는 안경을 모든 장면에서 썼다. 외모 글은 고른 그림 그대로 쓰므로 FLUX가 붙인 것으로 보인다

### 다음에 고칠 것 (같은 카드·시드로 다시 잰다)

1. 장면 글에서 글자를 그리라는 말(`written`, `reads`, `the numbers are`, `speaks`)을 지우고, `says`는 `speaks`가 아니라 지운다
2. 회상이 아닌 장면에도 extras 보정을 한다(장면 글에 나오는 이야기 속 인물을 넣음)
3. 한 장면에 시간·장소가 둘이면(`then`, `the scene shifts`) 앞쪽만 남긴다
4. 같은 사람이 두 번 그려지는 것은 프롬프트로 "each person appears only once"를 넣어 본다
